Wrapper:

- Classe de cada tipo primitivo

- As classes são escritas com a primeira letra maiuscula

- Exemplo: Integer, Double, Character, Boolean

- Estes tem acessos a métodos e atributos

- Você não pode converter de uma classe para a outra, exemplo: Integer para Double ou vice-versa



Tipo primitivo:

- Tipos primitivos de dados, sozinhos não representam muita coisa, mas você pode juntar e definir esse tipos primitivos como atributos de uma classe, por exemplo Cliente. O Cliente pode ter nome(string), idade(int), ativo(boolean).

- Estes não têm acesso a atributos e métodos, eles apenas armazenam um valor

- Nesse caso você pode converter de um tipo primtivo para outro tipo primitivo, depende do que você quer converter: int para double, é certo e o Java faz essa conversão de forma implicita. double para int, nesse caso é preciso fazer o cast, pois o double não cabe no int.



String:

- Toda String que você declarar vai ter acesso a atributos e métodos, logo não é um tipo primitivo.

- Você pode converter um tipo primitivo em uma String, mas o contrário deve-se pensar. Por exemplo nem toda String é um número, mas todo número é uma String.

public boolean equals(Object objeto) // cria um objeto com nome objeto {
		if (objeto instanceof Usuario) {  // garente que o tipo seja igual ao do Usuario
			Usuario outro = (Usuario) objeto; // faz cast de objeto para tipo Usuario
			boolean nomeIgual = outro.nome.equals(this.nome); // retorna true caso o nome seje igual
			boolean emailIgual = outro.email.equals(this.email); //retorna true caso o email seje igual
			return nomeIgual && emailIgual;
		}
		else {
			return false;
		}
	}

Padrão observer 

O padrão Observer define um mecanismo para que objetos observadores (Observers) sejam notificados sobre mudanças em um objeto observado (Subject), mantendo um baixo acoplamento entre eles.

Elementos principais
Subject (Sujeito/Observável)

Mantém uma lista de observadores.

Possui métodos para adicionar/remover observadores.

Notifica os observadores quando há mudanças no seu estado.

Observer (Observador)

Define uma interface para receber notificações do Subject.

Cada classe que precisa ser notificada implementa essa interface.

No contexto de modularidade, um Logger é um módulo separado e reutilizável que gerencia a geração de logs para diferentes partes do sistema.
Ele permite que outros módulos capturem eventos, erros e mensagens informativas sem precisar duplicar código.

1️⃣ logInfo(String message) → Registra mensagens informativas.
2️⃣ logError(String message) → Registra erros do sistema.
3️⃣ logDebug(String message) → Registra mensagens de depuração (opcional).
4️⃣ logWarning(String message) → Registra alertas (opcional).
